# Release checks

The open-source engine can be released independently of CCMP brochure approval. No unresolved CCMP statements are included in this public source package.

Before a document is circulated: resolve all facts, approve provenance and claims, inspect every rendered page, verify live link destinations, confirm image rights and resolution, record owner/date and current content/configuration/layout hashes. The default review ribbon is intentional. Do not bypass gates merely to remove it.

Before publishing this repository: choose the GitHub owner, run CI, retain font licence files, confirm no private assets or credentials were added, and publish the source. Tag a release only after the remote workflow succeeds. No remote release has been created by this preparation step.
